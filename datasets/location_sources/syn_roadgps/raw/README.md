# SYN-RoadGPS

SYN-RoadGPS is a road network-constrained synthetic GPS trajectory dataset for trajectory modeling and evaluation.

The dataset contains synthetic trajectories represented by road segment identifiers, timestamps, within-segment position ratios, and reconstructed GPS coordinates.

The raw source GPS trajectory records are not publicly released due to privacy and access restrictions. The released data are synthetic and are intended for research on synthetic trajectory generation, road-constrained trajectory modeling, spatial-temporal fidelity evaluation, and downstream tasks such as next-location prediction.
